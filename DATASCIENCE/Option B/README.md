# Vision Telegram Bot (Image Captioning)

## Features
- Accepts image input from Telegram
- Generates captions using BLIP model
- Extracts keywords/tags
- Fast and simple architecture

## Tech Stack
- Transformers (HuggingFace)
- BLIP model
- Python Telegram Bot

## Setup

pip install -r requirements.txt

Run:
python app.py

## Usage
Send image → get caption + tags
